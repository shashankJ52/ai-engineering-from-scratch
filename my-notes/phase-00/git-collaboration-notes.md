# Git & Collaboration Notes

## What I learned

- git status shows changed files.
- git add stages files.
- git commit saves a snapshot.
- git push uploads changes to GitHub.
- branches let me experiment without breaking main.

## My daily workflow

1. Check status
2. Make changes
3. Add files
4. Commit
5. Push to GitHub

## AI project gitignore lesson

Model checkpoint files should not be committed because they are usually large generated files.

Examples:
- .pt
- .pth
- .safetensors
